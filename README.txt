VANITY SALON WEBSITE - QUICK START

1) Open index.html in Acode or another code editor.
2) Preview index.html to test the site.
3) Add the real Vanity Salon media into the assets folder using these exact filenames:
   - vanity-hero.jpg       (hero image)
   - vanity-interior.jpg   (about section image)
   - gallery-interior.jpg
   - gallery-styling.jpg
   - gallery-hair.jpg
   - gallery-beauty.jpg
   - salon-video.mp4       (short salon clip)
4) Keep the filenames exactly the same, or edit the corresponding paths in index.html.
5) The gallery opens images in a lightbox and plays the salon video.
6) The booking form validates required fields and opens WhatsApp with a pre-filled appointment request.
   It does NOT confirm bookings automatically.
7) Review rating/count currently display the values supplied in the brief (4.8 / 5 and 631 reviews).
   Verify these on the live Google Business Profile before publishing.
8) Opening hours, individual review excerpts, social links and service prices were not supplied, so they have not been invented.

IMPORTANT:
- This is a front-end website. The WhatsApp form opens a message; it does not store customer data or manage appointments.
- Custom domain, advanced booking/database features and any paid hosting add-ons may cost extra.
- Use genuine salon photos/videos only after confirming you have permission to publish them.
